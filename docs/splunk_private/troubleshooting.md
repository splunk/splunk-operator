# Troubleshooting

SOK debugging works best when you move layer by layer. Start with the Kubernetes API, then the SOK controller, then owned Kubernetes resources, then containers, then Splunk Enterprise runtime state. Make sure to keep this content specific to internal practices. Anything that could be useful for customers or external contributors should be included in external pages.
