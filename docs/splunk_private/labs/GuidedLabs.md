# Guided Labs

Each file in this folder guides you through end to end setup of a Kubernetes environment, the Splunk Operator for Kubernetes (SOK), and a Splunk Enterprise instance. Many contain similar steps, however, each Splunk Enterprise deployment includes different capabilities. They get progressively more complicated in order of the files.
